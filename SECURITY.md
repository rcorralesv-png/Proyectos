# Política de Seguridad

## Alcance

Este repositorio es un **laboratorio educativo** diseñado para la enseñanza de conceptos de
CI/CD y DevSecOps en entornos académicos. No hay sistema de producción asociado, no se
procesan datos de usuarios reales, y no hay credenciales, APIs, o servicios en línea
configurados en este proyecto.

## Reporte de Vulnerabilidades

Si identificas una vulnerabilidad en el código de este laboratorio — por ejemplo, un
ejemplo de código inseguro que podría confundir a los estudiantes, o una configuración
que contradice los principios de seguridad que el laboratorio busca enseñar —
puedes reportarla abriendo un **Issue** en este repositorio con la etiqueta `security`.

## Tokens de Ejemplo

Los fragmentos de código y configuración que muestran tokens, claves o credenciales
son **ejemplos ficticios** con fines exclusivamente educativos. Ningún valor en este
repositorio representa una credencial real o activa.

Ejemplo visible en el laboratorio:
```
FAKE_DEMO_TOKEN=ghp_EXAMPLE_NOT_REAL_DO_NOT_USE_1234567890ab
```

## Reporte Responsable

Si por alguna razón este repositorio se utilizara como base para un proyecto real y
encontraras una vulnerabilidad con impacto real, el canal apropiado es abrir un Issue
privado (si la opción está disponible) o contactar al instructor a cargo del curso.

No se requiere un proceso formal de CVE para un laboratorio académico de este tipo.
